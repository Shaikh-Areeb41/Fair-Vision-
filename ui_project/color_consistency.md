## Prompt for Code Generation

**Objective:**  
Enhance an existing project while maintaining **chromology consistency**—keep the color scheme and theme coherent.

**Instructions:**

1. Ensure all new elements maintain the **existing color logic and palette**.
2. Implement a fully functional **Dark Mode** and **Light Mode** feature.
3. Carefully manage **contrast and readability**—ensure Light Mode and Dark Mode use black and white contrasts effectively.
4. You have **creative freedom** to improve UI/UX, animations, or visual enhancements.
5. Maintain **clean, maintainable, and consistent code** with the current design standards.

**Outcome Expected:**

- Fully functional Dark and Light Mode.
- Consistent color logic (chromology).
- Visually appealing with high contrast and intuitive usability.
